# Weather Comfort Analytics frontend

React and Vite frontend for the Weather Comfort Analytics application.

See the [project README](../README.md) for setup, authentication,
environment configuration, testing, and application architecture.

## Commands

Run from this directory:

- `npm ci` — install locked dependencies.
- `npm run dev -- --port 5173 --strictPort` — start local development.
- `npm run lint` — check JavaScript and React code.
- `npm run build` — create the production build.
